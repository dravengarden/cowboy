## Evidence, not a local guess

Only a validated terminal response from the original native process/operation
can become `budget`. This sync was refused by native replacement admission
before mutation; unrelated writers may still change the buffer. Local capacity
errors, deadlines, cancellation and transport failures are not this outcome.
Partial content, versions, retry hints, unknown reasons and foreign identities
are rejected. No layer resolves a replacement process or path to explain it.

- Apply still records uncertainty and consumes its single attempt before I/O.
  Missing or malformed replies retain Unknown and the existing exclusion.
- Only original-ID Query can reconcile uncertainty. A later exact Budget result
  follows the existing terminal-refusal transition; duplicate Apply and Query
  return retained evidence without another native operation.
- Adapter/Machine/Service clear only that terminal operation's local read fence.
  Terminal records and capacity remain until explicit Retire.
- Web keeps ordinary buffer use fenced until separately confirmed retirement,
  presents the resource-limit reason, never offers another Apply, and requires a
  fresh buffer observation afterward. Retirement is not release or recovery.

## Reader and rollout boundary

This extends a refusal reason, not the request shape, purpose or ownership
protocol: native/adapter APIs remain 1, Machine sync requires protocol 20, and
the HTTP envelope remains `apiVersion: 1`. An older closed reader rejects the
unknown reason and retains Unknown, never relabelling it Source or rearming
Apply. Update readers before relying on Budget reconciliation.

The `1.17.0` adapter deliberately retains Unknown for native Budget. Updating
Controller/Web cannot settle owners retained by that old process; installing a
new Plugin cannot migrate them to its new process either. Machine maintenance,
exact signed Plugin installation and independent recovery of historical unknown
owners remain separate acceptance boundaries.

Budget replies, observer loss, query-only reconciliation, terminal monotonicity,
