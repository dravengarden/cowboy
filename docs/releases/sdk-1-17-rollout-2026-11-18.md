# Plugin SDK 1.17 fleet rollout — 2026-11-18

Status: Controller, Web and all four Machines run Cowboy `496c876c`; the six
Agent Provider releases of component release 3.111.0 are published and
installed.

## Why

Component release 3.111.0 (`6d932fb4`) moved every Plugin to plugin-sdk
1.17.0 and provider-sdk 3.4.0, but no Controller, Machine or Plugin release had
followed. claude-code 3.20.44 (`153b9056`, steering waits for a running
compaction) depended on that lineage.

## Source fixes

- `1d90b1b1`: 3.111.0 had not refreshed the fixed-output Cargo vendor hash, so
  every Rust release output failed the Cargo.lock consistency check.
- `496c876c`: the `cowboy-workers` pin advanced from `84e0e683` to `1d90b1b1`
  (worker generation `worker-523905c470f5abfe0220`). The SDK and wire changes
  made the old pin refuse every host-only Machine release. Evidence:
  [`sdk-1-17-worker-pin-2026-11-18.json`](../experiments/sdk-1-17-worker-pin-2026-11-18.json).
