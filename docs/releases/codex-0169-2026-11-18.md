# Native Codex 0.169.1 (GPT-6.2) — 2026-11-18

Status: published from `b51fc476` (component release 3.114.0) and installed
on all four Machines.

## Why

Native Codex `0.169.1` is the first release whose bundled model catalog
carries `gpt-6.2-sol` and `gpt-6.2-astra`. Codex ACP `2.7.0`, still the latest
stable release, declares `@openai/codex ^0.166.0`; its newest preview
(`v2.7.1-preview.2`) declares the same. Following the third-party
"ahead of upstream when needed" principle ([`third-party.md`](../third-party.md)),
Cowboy adopts the native release now through a delta instead of waiting.

## Native schema

`codex app-server generate-ts --experimental` from `0.169.1` removes no type,
field or string literal of `0.169.0`'s schema; the 2026-11-17 record shows
`0.169.0` only added to `0.166.0`'s. Across `0.166.0` → `0.169.1`, the only new
required fields in client-to-server parameters or server requests belong to a
new MCP elicitation mode, `openai/userVerification`. ACP neither routes that
mode to ACP elicitation nor to its permission fallback, so such a request is
not presented; Cowboy configures no MCP server that sends it.
